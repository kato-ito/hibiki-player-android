# Hibiki Player（安卓版）

桌面版 **Hibiki Player**（波形 · 频谱 · 歌词 · Apple Music 风格音乐播放器）的安卓版本。
保留桌面版全部主要播放功能，界面按 **Apple Music（iOS）移动端** 风格重新设计：底部标签栏、
迷你播放条、全屏正在播放、歌词高亮、毛玻璃模糊背景。

## 〇、安装包

仓库只提供源码，安装包通过以下两种方式获取：

1. **直接下载**：到本仓库 Releases 页下载 `Hibiki Player v2.30.1*.apk`（功能完全相同，按机型选一个即可）；
2. **自行构建**：见下方「方式 B：构建 APK」。

| 文件 | 大小 | 适用 |
| --- | --- | --- |
| `Hibiki Player v2.30.1.apk` | 26.9 MB | **通用包**（arm64-v8a + armeabi-v7a），推荐 |
| `Hibiki Player v2.30.1 arm64.apk` | 13.5 MB | 仅 64 位机型（2017 年后基本都支持） |
| `Hibiki Player v2.30.1 armeabi-v7a.apk` | 14.2 MB | 仅 32 位老机型 |

| 项目 | 值 |
| --- | --- |
| 包名 / 版本 | `com.zai.hibikiplayer` / 2.30.1 |
| 支持系统 | Android 7.0 及以上（minSdk 24，targetSdk 35） |
| 签名 | **v2 + v3** 方案（见「八、安装包与签名」） |
| 权限 | 仅 2 项：网络（本地回环，播放本地文件用）、麦克风（可视化用，可选）；**不需要存储权限** |
| 其中内置 | 页面引擎（301 KB）+ 原生桥 + 本地 HTTP 服务 + **FFmpeg 解码库**（杜比/DTS 解码） |

安装三步：① 传到手机（数据线 / 微信文件传输助手 / QQ / 网盘）→ ② 点开 APK →
③ 按提示允许「安装未知应用」（如出现 Play 保护提示选「仍要安装」）。

> 自行构建 release 包需要签名密钥（`android/keystore.properties` + `.jks`）：两者都已加入 `.gitignore`，
> 不会随仓库分发，请在本机与备份中保管。缺少密钥时构建出的是**未签名包，无法安装**；覆盖升级旧版本也必须用同一把密钥。

## 二、两种使用方式

### 方式 A：直接使用（无需构建）

把 `www/index.html` 拷到手机上，用浏览器打开即可使用（或电脑浏览器打开预览）。
浏览器模式下：

- 导入文件用系统文件选择器（多选 / 目录上传）；
- 歌单与设置保存在浏览器本地（IndexedDB / localStorage），下次打开自动恢复；
- 说明：手机浏览器的「目录上传」支持有限，完整文件夹导入请用 APK 版。

### 方式 B：构建 APK（完整版，推荐）

1. 安装 [Android Studio](https://developer.android.com/studio)（自带 JDK 17 与 SDK）。
2. 打开 `android/` 工程目录，等待 Gradle 同步（自动下载 Gradle 8.10.2 / AGP 8.7.3 / Kotlin 2.0.21，
   国内网络可参考文末镜像提示）。
   > 解码库 `com.arthenica:ffmpeg-kit-min:6.0-2` 已从 Maven Central 下架，工程里已把
   > **阿里云 / 华为云 Maven 镜像**配置为它的来源（见 `settings.gradle.kts`）。
   > 若镜像也不可用，可手动下载后放成本地依赖：
   > `https://maven.aliyun.com/repository/public/com/arthenica/ffmpeg-kit-min/6.0-2/ffmpeg-kit-min-6.0-2.aar`
   > → 放到 `android/app/libs/`，并改 `dependencies` 为 `implementation(files("libs/ffmpeg-kit-min-6.0-2.aar"))`。
3. 连接手机（开启 USB 调试）→ 点运行；或菜单 **Build → Build APK(s)** 生成安装包。
4. 安装后打开 **Hibiki Player**：新建歌单 → 导入音频（或整个文件夹，含子目录）→ 开始播放。

APK 版与浏览器版的区别（全部由安卓桥提供，页面同一份代码）：

| 能力 | 浏览器版 | APK 版 |
| --- | --- | --- |
| 导入多个音频文件 | ✓ | ✓（系统文件管理器多选） |
| 导入整个文件夹（含子目录，自然排序） | 部分浏览器 | ✓（SAF 目录树，持久授权） |
| 歌单 / 设置 / 歌词持久化 | ✓ | ✓ |
| 重启后文件仍可播放 | ✓（需浏览器保留数据） | ✓（注册表 + 持久 URI 授权） |
| 播放时拖动进度条（HTTP Range 断点） | ✓ | ✓ |
| 锁屏 / 通知媒体控制（MediaSession） | 部分浏览器 | ✓ |
| 麦克风可视化 | 需 https/localhost | ✓（应用内授权） |
| **杜比 / DTS 解码播放**（AC-3 / E-AC-3 / TrueHD / DTS / WMA） | — | ✓（内置 FFmpeg） |
| **多声道 PCM 输出**（手动选「原生输出 / 下混输出」） | — | ✓ |
| **歌曲分类浏览**（全部歌曲 / 按专辑 / 按艺人） | — | ✓ |
| **B 站音频下载**（含扫码登录 / 分享进入 / 剪贴板识别） | — | ✓ |
| 系统返回键逐层关闭界面 | — | ✓ |

## 三、保留的桌面版主要功能

- **歌单**：矩阵卡片（封面自动取歌单内歌曲封面，可设为第一首 / 最后一首 / 自定义图片）、
  新建 / 删除歌单（二次确认）、多歌单切换，重启自动恢复上次歌单；
- **导入**：多选音频文件、整个文件夹（递归、按名称自然排序、自动筛选音频格式）、
  重复文件自动跳过；
- **播放**：点击曲目播放、点当前曲目暂停/继续、上一首/下一首、快退/快进 15 秒、
  进度条拖动跳转、音量与静音、四种播放模式（列表循环 / 单曲循环 / 顺序播放 / 随机播放）、
  文件缺失自动跳过并提示「⚠️ 缺失」；
- **播放界面**：全屏封面 + 封面模糊背景、标题/歌手（读内嵌标签：MP3 ID3 / FLAC / M4A·MP4）、
  无封面时按文件名生成稳定渐变占位；
- **Apple Music 风格界面与动效**：底部标签栏为毛玻璃 + 发丝分隔线 + SF 风格图标（选中变填充态）；
  迷你播放条为**悬浮圆角卡片**（留边、投影、内置底部进度线）；打开播放界面时封面从迷你条位置
  **放大 Morph 进入**、收起时缩回；列表与歌单卡片逐条淡入、按压有缩放反馈；
  统一使用 iOS 缓动曲线（`cubic-bezier(0.32,0.72,0,1)`）；
- **歌词**：载入 .lrc（同名自动配对 / 手动选择）、逐行高亮滚动跟随、点击歌词行跳转、
  手动滚动后暂停跟随 3 秒，歌词持久保存；
- **可视化**：波形 / 频谱实时数据图（频谱频率上限随文件采样率自动适配：
  44.1k 显示到 22.05 kHz、96k 到 48 kHz……）、麦克风实时输入模式；
- **杜比 / DTS 解码播放**：AC-3、E-AC-3（杜比全景声）、TrueHD、DTS、WMA 由内置 FFmpeg
  解码为 PCM 播放（保留原始采样率与声道布局；歌单显示「解码…」进度；结果按文件+模式缓存，
  240 MB 预算 LRU 淘汰）；
- **杜比输出方式（手动选择）**：设置页用 iOS 分段控件提供两档 ——「**原生输出**」（保留 5.1 / 7.1
  原始声道布局，交系统空间音效渲染）与「**下混输出**」（按当前输出设备声道数重编码降混：
  7.1 → 5.1、设备仅立体声时降为 2.0，由解码器按标准系数下混）；面板显示当前输出设备声道数，
  播放界面 ⋯ 菜单可一键切换，界面实时标注实际去向（「5.1 多声道直出」/「5.1 已下混为 立体声」）；
- **音频数据**：文件名 / 格式 / 大小 / 采样率 / 码率 / 特殊格式 / 解码输出；
- **皮肤**：暗夜绿（默认）/ 白色 / 复古三套主题 + 自定义背景图（浓度可调）；
- **歌曲分类**：资料库顶部分段控件 ——「**歌单** / **歌曲** / **专辑** / **艺人**」四栏：
  「歌曲」按名称列出全部歌曲（跨歌单去重，行内显示「艺人 · 专辑」）；
  「专辑」「艺人」自动按内嵌标签归类（无标签归入「未知专辑 / 未知艺术家」并排在最后），
  专辑为两列封面网格、艺人为圆形头像列表；点任一专辑 / 艺人进入独立详情页（封面 + 曲目数 +
  总时长 + 「播放」按钮按该分类顺序入队播放），曲目行可单点播放或经 ⋯ 菜单「从「歌单名」移除」；
  标签解析按 4 路并发分批进行，解析完成后列表自动归位并刷新；当前分类关闭应用后仍会记住；
- **搜索**：歌曲 + 歌单分组结果（可按歌曲名 / 艺人 / 专辑命中）；
- **排序**：长按歌曲拖动调整顺序（自动保存，正在播放不中断）；
- **多选管理**：逐曲菜单「删除 / 多选 / 音频数据」，多选批量删除；
- **队列**：播放队列面板（当前曲高亮 + 均衡器动画）、面板内切换播放模式；
- **隐私**：所有数据只存本机，无任何联网上报（与桌面版一致）。

## 四、B 站音频下载（手机场景）

界面：资料库右上角「⤓」入口 → 独立下载页（解析 / 音质 / 分P / 任务 / 账号）。

| 手机用法 | 说明 |
| --- | --- |
| **分享进入** | 在 B 站 App「分享 → Hibiki Player」（`ACTION_SEND` intent）→ 自动打开下载页并解析 |
| **剪贴板识别** | 复制链接后切回应用（`onResume` 读剪贴板）→ 顶部横幅提示「检测到剪贴板链接」→ 点解析 |
| **手动粘贴** | 输入框粘贴 BV / av / b23.tv / 整段分享文案（正则提取链接） |
| **短链解析** | b23.tv 302 跳转自动展开为真实链接 |
| **扫码登录** | 面板内本地绘制二维码（MIT 库，不经过任何第三方图片服务），轮询状态：等待 → 已扫待确认 → 成功；登录后解锁 Hi-Res 无损 FLAC / 杜比全景声 |
| **分P 多选** | 多P视频列出全部分P，默认只选第一P，可多选后批量下载 |
| **进度与取消** | 任务卡片显示百分比 / 已下载 / 速度，可随时取消（取消会中断 CDN 响应流） |
| **保存与入库** | 写入手机「音乐/Hibiki Player」（Android 10+ 走 MediaStore 免存储权限），完成后**自动登记并加入当前歌单**（无歌单则新建「B站下载」） |
| **前台守护** | 下载期间自动保持屏幕常亮，避免息屏被系统回收，任务结束后解除 |

管线（与桌面版一致，且经真实接口验证）：`view` 取信息 → `playurl(fnval=4048)` 取 DASH 音频流 →
带 **PC User-Agent + Referer** 直连 CDN → 内置 ffmpeg **无损流拷贝**封装（AAC→M4A、Hi-Res→FLAC、
杜比→EAC3）+ 写入 标题/UP主/专辑/来源 标签 + 内嵌封面。

> 实测要点：B 站 CDN 对**移动 UA 返回 403**，必须使用 PC UA（见 `verify-bili-pipeline.js` 的断言）；
> `view` 与 `playurl` 当前无需 WBI 签名。

## 四·B、Windows 桌面端同步（本轮）

桌面版（Windows 桌面端工程，见另一方仓库 [hibiki-player](https://github.com/kato-ito/hibiki-player)）已同步的改动：

- **杜比下载保持原始 `.eac3`**（不是 MP4）：封面 / 标题 / UP主 / 专辑用**前置 ID3v2.3（含 APIC）**写入，
  音频码流原样不动；`bili-ipc.js` 新增 `RAW_STREAM_EXTS` / `writeId3ToRaw`；
- **下载限速**：下载面板新增「限速」按钮（不限 / 512 KB/s / 1 / 2 / 5 MB/s），保存目录设置桌面端本来就有；
- **FLAC 封面解析修复**：原来的图片块解析把大端字段当小端读、并按长度推算数据起点，封面易损坏；
  现改为按图片签名定位取到块尾（与安卓端同一实现）；
- **标签乱码兜底**：新增 `cleanTagText`（替换字符 / mojibake 判空 → 界面回退文件名）；裸流（eac3 等）
  也支持读取前置 ID3v2 标签。

验证方式：用桩 Electron 直接驱动桌面端**真实 IPC 链路**（真实接口 + 真 ffmpeg）：
普通 AAC 下载（`embedCover: true`）→ M4A 内含 attached_pic（可抽出 302 KB JPEG）+ 标签齐全，
对照组无封面；杜比下载（桩 playurl + 本地假 CDN）→ **MP4 容器（`.m4a` 文件名）+ E-AC-3 原始码流 +
covr 封面 + 中文标签** + 可解码为 PCM，6/6 通过。

Windows 安装包已重新打包（`electron-builder --win nsis`）并核验新包内含上述改动：

- `Hibiki Player Setup 2.15.1.exe`（93.3 MB，NSIS 安装包，SHA-256 `1587E92E…BFB2632B7`）
- `win-unpacked/`（免安装目录版）

## 六、常见问题

- **首次同步很慢 / 失败**：国内网络可在 Android Studio 设置镜像：
  `gradle-wrapper.properties` 的 distributionUrl 可换成
  `https://mirrors.cloud.tencent.com/gradle/gradle-8.10.2-bin.zip`；
  `settings.gradle.kts` 可添加阿里云仓库
  `maven { url = uri("https://maven.aliyun.com/repository/google") }` 等。
- **gradle-wrapper.jar 缺失提示**：工程内已附带 wrapper jar；
  若被安全软件清理，Android Studio 打开工程时会提示修复，同意即可自动补全。
- **导入的歌曲过一段时间打不开（⚠️ 缺失）**：文件被移动/删除/改名，或文件管理器
  （如部分网盘）不支持持久授权；重新导入即可。
- **修改 www-src 后生效**：`node www-src/build.js` 重新生成 `www/index.html`；
  APK 版需重新构建安装（页面随安装包分发）。
- **锁屏后继续播放**：Android 8+ 请将本应用加入电池优化白名单（不同厂商路径略异）。

  淘汰，而「刚解码完成的那一条」正是最新的写入者，旧逻辑会把它当普通条目删掉 —— 表现为解码成功却放不出声、

  ② **坏文件不再「不提示、也不跳下一首」**：`beginPlayback` 原来在 `stopPlayback` **之前**取播放代数号
